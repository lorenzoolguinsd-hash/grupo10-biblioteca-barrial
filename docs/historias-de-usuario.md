# Historias de usuario

## Introducción

Las siguientes historias de usuario describen las principales necesidades de las personas que utilizarán el sistema de gestión de la biblioteca barrial.

## Historias de usuario

### HU01 – Registrar libros

Como bibliotecario, quiero registrar libros indicando su título, autor y cantidad de ejemplares, para incorporar varios ejemplares al catálogo con códigos identificadores generados automáticamente.

### HU02 - Eliminar libros

Como bibliotecario, quiero eliminar libros del catálogo para mantener la información actualizada.

### HU03 – Buscar libros

Como bibliotecario, quiero buscar libros por título o código identificador, para consultar los ejemplares registrados. La búsqueda por título deberá mostrar los resultados agrupados por título y autor, mientras que la búsqueda por código permitirá identificar un ejemplar específico.

### HU04 – Consultar catálogo

Como bibliotecario, quiero consultar el catálogo agrupado por título y autor, para conocer la cantidad total de ejemplares, disponibles y prestados de cada libro.

### HU05 - Registrar socios

Como bibliotecario, quiero registrar nuevos socios para llevar un control de las personas que utilizan la biblioteca.

### HU06 - Consultar socios

Como bibliotecario, quiero buscar socios registrados para consultar sus datos.

### HU07 - Registrar préstamos de libros

Como bibliotecario, quiero registrar el préstamo de un libro a un socio para llevar un control de los ejemplares prestados.

### HU08 - Registrar devoluciones

Como bibliotecario, quiero registrar la devolución de un libro para actualizar su disponibilidad.

### HU09 - Consultar libros préstados por socio

Como bibliotecario, quiero consultar los libros que tiene prestados cada socio para conocer su situación actual.

## Consideraciones

Estas historias representan las funcionalidades previstas para la primera versión del sistema. Su alcance podrá ajustarse durante la etapa de análisis y diseño.
