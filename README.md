- **Entorno de desarrollo:** Eclipse
- **Integrantes:** Lorenzo Olguin, Ramiro Peralta, Francisco Olivera, Nestor Oviedo.

## Descripción del problema

Las bibliotecas barriales pueden tener dificultades para llevar un registro ordenado de sus libros, socios y préstamos cuando utilizan anotaciones manuales o registros dispersos.

Esto puede provocar pérdidas de información, confusiones sobre qué libros están disponibles y dificultades para saber quién tiene cada ejemplar.

## Solución propuesta

Desarrollar un programa en Java que permita administrar un catálogo de libros, registrar socios y controlar los préstamos y las devoluciones, manteniendo la información organizada mediante listas.

## Funcionalidades principales

- Registrar libros.
- Eliminar libros del catálogo.
- Buscar libros.
- Mostrar todos los libros registrados.
- Registrar socios.
- Buscar y consultar socios.
- Registrar préstamos de libros.
- Registrar devoluciones.
- Consultar los libros prestados por cada socio.

## Estructuras de datos

El proyecto utilizará colecciones y listas de Java (`List` y `ArrayList`) para almacenar y administrar la información.

También se implementará una colección de colecciones para representar los libros prestados por cada socio.
